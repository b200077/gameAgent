gameAgent AI 操作指南（2026-11-24 精簡版，內容對照 agent_core.py）
我只講遊戲名稱時，就是要你刷該遊戲的每日，直接照本指南開始，不用再問。

━━ 一、流程 ━━
1. 先開 Remote Control（set_remote_control self），要在「開啟」遊戲之前開。
   沒回傳 on（被拒、要核准、auto mode 無法審核）就停下，請我手動開好再繼續。
2. 讀 <遊戲資料夾>\AI備註.txt（若有），只讀這款遊戲的。
3. 用「開啟」開遊戲（會把遊戲帶到最上層），再跑 daily 等指令。
4. 跑完回報，問我要不要關遊戲，並列出沒跑的選用指令。
5. 我說「刷完」時：
   (1) 關遊戲（見下「關遊戲」），然後清理（見下）。
   (2) 根目錄執行 PYTHONIOENCODING=utf-8 python usage_report.py --summary
   (3) 用文字寫分析（不要只貼輸出）：總花費與呼叫次數和同遊戲前幾次比較、花最多的段落與原因、
       上下文暴增的步驟下次能否避開、截圖佔比（有無全螢幕或未縮放）、下次怎麼省。
       表格在 _usage\sessions.csv、turns.csv。
   (4) 整理該遊戲的 AI備註.txt：把這次的發現併進對應段落（已寫進腳本的只留結論，
       舊的同類紀錄合併或刪掉，未驗證的標明），不要只在最後追加日期段落，讓檔案保持精簡。
關遊戲：一般遊戲用 close-><視窗標題>。網頁遊戲（Chrome 分頁）不要用 close->，它會關掉整個 Chrome
  視窗連同其他分頁。改關分頁：截分頁列，找出遊戲分頁的 ×，用遊戲資料夾的 tab.png（分頁圖示加標題開頭，
  沒有就從截圖裁）點分頁讓它成為目前分頁，再 press->ctrl+w：tab,wait0.5,press->ctrl+w（オトギフロンティア 11-24 跑通，可寫成該遊戲的 關閉 指令）。
  關完再截分頁列確認只少了遊戲分頁。
清理：python clean_run.py --since "YYYY-MM-DD HH:MM" --until "..."（移到資源回收筒，只動該時段的
  _screenshot\*.png 與 _core_messages.log；其他工作可能也在截圖時先加 --dry-run；別人還在用 log 時加 --keep-log）。
  保留 _ai_command_log.txt 和寫回腳本的按鈕圖片。

━━ 二、基本規則 ━━
- 只用 gameAgent 操作電腦。難以控制的情況先問我。
- 用圖片／文字比對點擊，不點座標。付費頁面只比對明確的免費按鈕。
- 不買付費商品、不花付費貨幣，需要時先問。
- ai_run.py 會自動記錄指令到 <遊戲資料夾>\_ai_command_log.txt；其他方式送的（如 closeCore）
  自己記：時間<Tab>command/step/key<Tab>內容。
- 遊戲有更新（登入前下載資料）：下載完停住告訴我，讓我自己看公告。
- 維護或畫面異常：關遊戲（見一、流程「關遊戲」）並回報。「開啟」不偵測維護，會一直等。

━━ 三、位置 ━━
根目錄 F:\應用程式\遊戲腳本\；遊戲資料夾 根目錄\<遊戲名稱>\（commands.txt、按鈕 png、AI備註.txt）
截圖存在 根目錄\_screenshot\；core 訊息 根目錄\_core_messages.log；語法細節 README.md
cv2 用 F:\build\build_env\Scripts\python.exe
core 監聽 127.0.0.1:5200。連不上先問我，同意後：
  Start-Process -FilePath 'F:\應用程式\遊戲腳本\agent_core.exe' -Verb RunAs（我按 UAC）

━━ 四、送指令（一律背景執行，等待中不截圖） ━━
python ai_run.py "<遊戲資料夾>" --command daily [--start-index n]
python ai_run.py "<遊戲資料夾>" --step "步驟1,步驟2"
python ai_run.py "<遊戲資料夾>" --stop        結束執行中／暫停中的指令，core 不關
python ai_run.py "<遊戲資料夾>" --continue    AI() 接手後接續
--start-index n 從第 n 步開始（0 起算，:模組 算一步），接續用這個，不要手動重組步驟。
--silence 秒（預設 180，長戰鬥調大）；--max-run 秒（預設 600，整合指令建議 1200）。
RESULT：done 完成｜ai_handoff 走到 AI()｜timeout 圖片等 8 秒沒找到，core 已暫停｜paused｜stopped｜
  error 有 ❌（如缺圖）｜needs_input｜silence 長時間無訊息（常是 waitImg）｜max_run｜core_unreachable

━━ 五、看畫面 ━━
截圖：--step "screenshot(...)" --silence 15 --max-run 20，再讀 _screenshot 最新檔。暫停中也能截。
- 每次工作只有第一張截全螢幕（可縮 0.5），找出遊戲視窗範圍，之後都用
  screenshot(x_y_w_h_縮放) 只截遊戲；視窗位置每次可能不同，不沿用舊座標，內容不對時再截全螢幕。
- 固定區域用定位圖：screenshot(圖片_dx_dy_w_h_縮放)；跑通後記到 AI備註.txt。
- 小字或數字縮放不低於 0.7。不用自己寫 cv2 裁圖。
- 圖片比對要遊戲在最上層且沒被邊緣擋住（瀏覽器遊戲注意書籤列和工作列）。
- 遊戲被 Claude 擋住：minimize->claude.exe。focus-> 在 core 位於背景時常被 Windows 拒絕，
  會無聲中斷變成 silence；切不過去才叫我，用 wait8,screenshot 等我切換。
  focus-> 依標題找，可能切到同名的 gameAgent UI 視窗，改用 exe 名稱（例 focus->ドットアビスX.exe）。
- login bonus：多半點畫面任一處（mouseClick）或右上跳過就過；圖片比對沒找到改 mouseClick。

━━ 六、暫停與異常 ━━
- 模擬的 ESC 無效（pyautogui、press->esc 都不行），一律用 --stop；沒回應才 closeCore（之後要重開按 UAC）。
- 暫停中的舊指令還活著：實體空白鍵會讓它恢復，和新指令一起亂點。core 監聽全域鍵盤，
  聊天框打字（含輸入法空白鍵）也算。所以：送會點擊的新指令前先 --stop；執行中提醒我別按空白／Tab、別動滑鼠；
  發現多條指令同時跑就立刻 --stop 並回報。
- AI() 接手（ai_handoff）：「🤖 AI接手:」後是要做的事，「📸 已截圖」是當下畫面。用 --step 完成後 --continue。
  --step 不影響接續，--stop 會清掉接續點。每次都能用固定步驟處理時，建議把 AI(...) 換成那些步驟。
- waitImg 變成 silence：先截圖，常是在等我自己選或長戰鬥，不要 --stop 也不要替我選，告訴我在等什麼。

━━ 七、卡住時與寫回腳本 ━━
1. 先截圖判斷原因，不要猜、不要先按畫面上的按鈕。沒看過的畫面常是前一步沒點到，應回頭補做。
2. 缺按鈕就從截圖裁 png 放進遊戲資料夾（座標以 1920x1080 為準）。路徑含中日文時 cv2.imwrite/imread
   會無聲失敗，改用 cv2.imencode('.png',img)[1].tofile(路徑) / cv2.imdecode(np.fromfile(路徑,np.uint8),cv2.IMREAD_COLOR)，
   存完 ls 確認。
3. 捲動：move->固定定位圖,mouseMove(x_y),scrollDown*n；太多用 scrollDown(100) 微調；滾輪無效用 drag(x_y)。
   定位圖不可含倒數等變動內容。捲動距離依遊戲而異，先試一次再計算。
4. 「執行了但沒點到」多半是冷卻：前面加 wait0.1 或後面補一次 按鈕?。會開視窗或扣資源的按鈕不要補點，改加等待。
5. 臨時測試的點擊都加 ? 再接 screenshot（沒加 ? 找不到會暫停，要先 --stop）。
跑通後：寫回 commands.txt 對應指令並保留新圖；先試現有圖（門檻 0.8）；只改相關步驟（commands.txt 不在 git）；
沒跑通或推測的不寫，改成建議；告訴我改了什麼、哪些未驗證；單一遊戲的發現寫進該遊戲 AI備註.txt。

━━ 八、commands.txt 語法 ━━
格式 指令名:{步驟1,步驟2}；圖片步驟寫檔名（不含 .png）；名稱以 _ 開頭不顯示但可呼叫。
只能用下列語法，不發明新指令；做不到時回答「❌ 無法產生腳本：缺少對應指令」；只要求產生腳本時只輸出腳本。

圖片修飾：? 找不到約 0.6 秒跳過｜↑ 找不到約 0.4 秒重試上一步（上一步要能重複成功）｜✓ 點擊後確認消失｜
  無修飾 等 8 秒，找不到暫停｜#n 第 n 個相符（負數倒數）｜%scale 縮放｜@文字 OCR 判斷（支援 > < >= <= == !=）｜
  a|b 任一出現就點｜Text(文字) OCR 找文字。例：skip3?,ok↑ 持續按 skip3 直到 ok 出現
等待：wait1 / wait0.5｜wait14:30 等到時間｜waitImg->圖片 無限等待不點擊，不會超時｜
  waitPress->按鍵｜waitClick
滑鼠鍵盤：move->圖片｜mouseMove(x_y) 相對｜mouseMoveTo(x_y) 絕對｜mouseClick / rightClick｜
  scrollUp / scrollDown（預設 500）、scrollDown(n)｜drag(x_y) / drag(x_y_秒) 從目前位置拖（預設 0.5 秒）｜
  press->按鍵、press->ctrl+w 組合鍵｜"文字" 剪貼簿貼上｜@圖片->驗證碼圖片#位數
視窗開啟：focus-> / close-> / minimize->標題或 xxx.exe｜http(s)://網址｜.lnk / .exe / dmmgameplayer://... / 資料夾｜
  screenshot、screenshot(x_y_w_h_縮放)、screenshot(圖片_dx_dy_w_h_縮放)（找不到定位圖略過）｜match->圖片 印比對分數｜obsStart / obsStop
流程：*數字 重複｜:模組名、:模組名$參數1$參數2（模組內 $1 $2）｜callCommand:指令名（可遞迴）｜
  nextCommand 略過下一步｜previousCommand｜exitCommand｜
  AI(說明) / AI 交給你（core 截圖後停下，空白鍵不會恢復；說明不能有半形逗號，用「，」「、」）
條件（前加 ! 相反）：week-Sun->步驟（Mon~Sun）｜date-15->步驟｜img-圖片->步驟｜img-圖片@>50->步驟
範例：train:{train,getAll,ok,confirm,wait2.5,back}　alignment:{:train,:daily}
